# 디자인 노트

## 재해석 원칙

1. 참고한 것은 정보 구조(섹션 종류와 순서)뿐이다.
2. 비주얼, 카피, 로고, 컬러, 타이포, 그리드는 브랜드 컨셉에서 새로 도출한다.
3. 가상 브랜드임을 푸터와 보증서 일러스트("예시")에 분명히 표시한다.

## 브랜드

- 이름: 앵커보증 (가상). 닻 모양 심볼은 원, 세로선, 가로선, 호 네 개의 획으로 그린 자체 제작 마크.
- 핵심 오브젝트: 보증서. 이 업종에서 가장 상징적인 문서를 Hero의 단일 주인공으로 둔다.

## 타이포

- 제목: Noto Serif KR 600/700
- 본문: Noto Sans KR 400/500/700
- 본문 크기 15–17px, 제목 26–48px

## 레이아웃

- 최대 폭 1280px, 좌우 패딩 32px(모바일 20px)
- 데스크톱 기준 breakpoint: lg(1024px)에서 GNB 전환
- 카드 남발을 피하고 구분선 위주로 정보를 나눈다. 채운 면은 Hero, 배너 1개, 푸터에만 쓴다.

## 모션

- 페이지 로드 시 인장이 찍히는 모션 1회. 그 외는 사용자 동작(hover, 열기/닫기)에만 반응.
- `prefers-reduced-motion`에서는 전환을 사실상 제거.
